Experience replay

A 100,000-transition buffer stores past interactions, from which random batches of 64 experiences are sampled for each learning update.

02

Epsilon-greedy

The agent starts by exploring and gradually shifts toward exploiting its learned policy.

03

Target network

A slowly updated target network provides a more stable Bellman learning target.
